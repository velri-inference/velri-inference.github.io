Velri

Native neural-network inference engine, C23 compute library, and VTQ trellis weight quantization.

C23 / C++23 Khronos Slang AOT CPU & Vulkan 1.3 VTQ v2 (1.5–6.0 bpw) GNU GPLv3

Velri is an open-source inference stack for Linux, Windows, and Android built to run models whose weights exceed GPU VRAM through explicit memory planning and hybrid CPU+GPU execution. Compute kernels are authored once in Khronos Slang and compiled ahead of time (slangc AOT) for x86-64 (base, AVX2, AVX-512 VNNI), ARM64, RISC-V 64, and Vulkan 1.3 / SPIR-V 1.6 — with zero Python, PyTorch, CUDA, LLVM, or Slang runtime dependencies and zero heap allocations per inference step after prepare.

3. Build & Integration

Requires CMake 3.21+, Ninja, Clang 18+ or GCC 14+ (C23), and build-time Khronos Slang (slangc).

git clone https://github.com/velri-inference/velri.git
cd velri
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=clang -DVELRI_ENABLE_VULKAN=ON
cmake --build build
ctest --test-dir build --output-on-failure

Standalone VelriLib::velri consumption via installed CMake package:

find_package(VelriLib 0.7.0 EXACT CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE VelriLib::velri)

4. Technical Notes

Implementation stack
Velri and Velri-lib are implemented in C23 and C++23 behind a pure C23 public API, with CPU and Vulkan 1.3 compute kernels compiled AOT from Khronos Slang. Velri is not written in Rust and does not depend on CUDA, Python, PyTorch, LLVM, or libslang at runtime.
VTQ vs EXL3 and GGUF
VTQ packs weights into 64-byte-aligned 16×256 supertiles using a 256-step tail-biting Ungerboeck trellis (1,024 states, 16 subsets), Outer-DCT/Kronecker-Hadamard rotation at 16-row granularity (avoiding EXL3's +9% padding overhead on non-power-of-two MoE widths like 704), and global Row-Fisher DP bit allocation.
CPU decoding without AVX-512
VTQ CPU codebooks (s8_32, u8, at2_16_16, at2z_32_32) target AVX2 vpshufb (-mno-avx512f) without vpblendvb or runtime Galois popcounts, using the identical binary layout shared across disk and GPU.
Relation to historical LTQ and .liqk
LTQ and .liqk were earlier quantization prototypes preserved in vtq-research/src/ for reproducibility. VTQ (.vtq v2) is the active format for Velri.
