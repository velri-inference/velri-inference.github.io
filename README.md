# velri-inference.github.io

Static landing site, Schema.org JSON-LD metadata, `sitemap.xml`, and unified LLM discovery files (`/llms.txt`, `/llms-full.txt`) for the **[Velri Inference](https://github.com/velri-inference)** ecosystem:

- **[velri](https://github.com/velri-inference/velri)** — Native C23/C++23 + Khronos Slang AOT LLM inference engine (CPU & Vulkan 1.3)
- **[velri-lib](https://github.com/velri-inference/velri-lib)** — Standalone C23 tensor, execution graph, and Slang AOT compute library
- **[vtq-research](https://github.com/velri-inference/vtq-research)** — **VTQ** (*Velri Trellis Quant*, `.vtq` v2) hardware-co-designed `16×256` trellis weight quantization
